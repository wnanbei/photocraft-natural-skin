# Security

Natural Skin is an import-free WebAssembly image filter. It does not request filesystem or network access. The PhotoCraft host provides the pixel buffer and runs the module in its own sandbox.

For a suspected memory-safety, sandbox, or artifact-integrity issue, use [GitHub private vulnerability reporting](https://github.com/wnanbei/photocraft-natural-skin/security/advisories/new) if enabled. Otherwise, open an issue asking for a private reporting channel without publishing exploit details or private images. Report host sandbox vulnerabilities to the PhotoCraft project as well.

The latest released version is the supported line. Include plugin and PhotoCraft versions, OS, a minimal synthetic reproduction when possible, and the affected artifact's SHA-256. Do not attach private portraits or credentials.
