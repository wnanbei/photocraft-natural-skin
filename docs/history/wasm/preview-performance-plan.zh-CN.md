# 预览性能与实施边界

项目标准：只修改插件，不修改 PhotoCraft 主程序。当前优化继续使用 ABI v1 和原有磨皮算法。

1.1.1 已采用的优化：

- 蒙版与 Strength=0 纯调色不分配邻域滤波缓存。
- 跳过无肤色图块，裁去未命中的边缘。
- 对分散肤色区域保留完整邻域后分别计算，按最大区域分配并复用缓存。
- 对密集、细碎或预计不划算的区域自动使用原路径。
- Texture=0 跳过纹理邻域计算，不透明区域使用等价快速路径。

当前区域优化的测量与验证见[性能记录](skin-region-performance-1.1.1.zh-CN.md)。历史矩形裁剪记录见[首次 ROI 验证](roi-performance-1.1.1.zh-CN.md)。

主程序决定预览尺寸、可见区域和刷新时机；现有主程序每个 band 新建 WASM 实例，插件不能跨预览请求保留缓存。ABI 也没有可靠的预览/正式应用标记。这些边界不通过插件隐藏开关或变更半径单位绕过。

调色时可先确定磨皮，再重新打开插件，设置 Strength=0、关闭 Show_Mask 后调整美白和红润。第二步不重新计算磨皮；两步分别可以撤销。

CLI 处理耗时不是 GUI 首帧延迟或拖动帧率。本版尚未完成 GUI 连续拖动和跨平台交互验证；稀疏区域提速也不保证每张大图都会更快。
