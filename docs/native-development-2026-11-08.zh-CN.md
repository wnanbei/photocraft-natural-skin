# 原生桌面开发版：2026-11-08

本轮从可行性后端推进到 **Windows/macOS 共用的 Rust + egui 桌面开发版**。用户明确选择首版跨平台，因此没有采用 macOS 专用的 SwiftUI。没有修改 PhotoCraft，也没有恢复 WASM 产品线。

## 已落地

| 部分 | 实现 |
| --- | --- |
| 原始数据交换 | Rust 原生 `.pcraft` ZIP 读写，无 Python/zstd 外部程序运行依赖；按 U8/U16/F32 解析图块 |
| 数据保留 | 透明像素下 RGB、Alpha、ICC、DPI、负图块坐标/画布外数据、边缘图块 padding；保留文档 JSON 和二进制元数据 blob |
| 文件校验 | 仅格式版本 1；先限制 ZIP 目录再建立索引，检查重复名/本地头一致性/CRC/BLAKE3、图块尺寸和解压预算 |
| 文件发布 | 新文件通过同目录临时文件写完后发布，不覆盖已有路径；写失败清理临时文件；删除已失效的平面预览引用 |
| 原生界面 | 打开/拖入文件、原图/结果切换、磨皮和调色控件、皮肤蒙版、重置、导出 |
| 后台任务 | 独立 worker，最多一个待执行请求；参数变化取消旧任务并合并预览，UI 按请求版本丢弃过期结果 |
| 原图保持 | 预览持有不可变源图；完整导出在私有副本上计算，写入失败也恢复原图数据，重复导出不累积效果 |
| 状态 | 真正的处理阶段、已用秒数、预览完成耗时/缓存状态、导出完成/取消/错误；文件提交阶段不假报取消成功 |

## 本地验证

本地 **35 个测试**、GUI 全目标严格 Clippy、macOS 打包和 Windows 目标编译检查通过。窗口已实际验证全部调节滑块、缓存复用、原图/蒙版切换、滚动/重置、不支持文档的拒绝与恢复、中文文件名和中文路径导出。原生文件面板已关联主窗口，避免独立面板跑到后台。最终 GUI 导出与同参数完整分辨率 CLI 输出比较，RGB/隐藏 RGB/Alpha 误差均为 0。验收摘要与产物哈希见 [JSON](native-development-2026-11-08.json)。

实际运行 **PhotoCraft 0.21.0（efb7ebd0c）** 的独立桌面实例，使用 267 × 259 的合成 RGBA 图跨越 4 个图块：8/16/32 位 × 原样/磨皮，共 6 组 `.pcraft` 捕获和回传。全部组别的可见 RGB、完全透明像素下 RGB、Alpha 最大误差均为 **0**；ICC、300 DPI、源文档保持和两次 Undo 恢复通过。回传时仅捕获新结果图层，避免把含原层和结果层的双层文档误作单层输入。

单元测试还覆盖了 RGB/RGBA、多图块、负坐标、稀疏默认像素、NaN 位模式、HDR 数据保留、边缘 padding、损坏/缺失对象、超限/新格式拒绝、失败不发布、异步预览及多次导出原图保持。

Windows 已通过 `x86_64-pc-windows-gnu` 的 GUI 全目标编译检查；这不等于生成 Windows 发行版，也不替代真实 Windows 文件对话框、图形驱动、Alpha 显示和文件发布测试。CI 已配置 Windows/macOS 原生构建，远端执行结果另行确认。

## 文件与资源范围

目前支持 ZIP 形式的 `.pcraft`，不支持目录形式。只接受一个可见 Normal 普通像素层、100% 不透明度/填充，无蒙版/剪贴/效果/选区/附加通道/时间线。复杂图层文档应先在 PhotoCraft 中复制目标层到独立文档。

完整图像上限 36 MP；预览长边不超过 1024。压缩包/累计对象解码预算 768 MiB、单 blob 16 MiB、manifest 2 MiB、条目最多 4096、Zstd 窗口不超过 8 MiB；极端细长画布也受填充图块预算限制。这些是交换预算，不是整个进程峰值内存承诺。

保存为 `.pcraft` 才保留画布外图块和文档元数据。显式转换为 TIFF 仅输出画布，且 PhotoCraft 的平面 TIFF 导出仍会丢失透明像素下 RGB。新文件发布依赖目标磁盘支持同卷硬链接；不支持的文件系统会报错，不降级为覆盖输出。

## 还需开发

- PhotoCraft 启动/连接/自动捕获的产品入口；现有接口缺少原子版本检查与应用，继续默认新文档回传。
- 更细的滤波取消与进度、可靠的 ETA、真实照片端到端性能与内存验收。
- ICC 显示转换、广色域/HDR 磨皮认证。当前预览按 sRGB 显示，不能因为文件保留 ICC 就宣称色彩管理已完成。
- 高倍率/1:1 局部预览；当前缩小预览是近似，最终导出用完整分辨率。
- Windows 实机验收，macOS 发行签名/公证、Windows 安装包和升级机制。
